##Commandes git

## git init
Permet d'initialiser un repertoire.

## git add
Permet d'ajouter un fichier pour des modifidications dans le staging.

## git commit
Permet d'enregistrer une modifidication en local.
Le message est important

## git push
Permet de pousser les modifications en ligne.

## git status
Permet de lister les modifications a traiter.
Permet de verifier le statut du repertoire.

## git log
Permet de lister les historique de modifications

## git log --oneline
Permet de lister les historique de modifications de maniere compacte.

## git branch
Permet de lister les branches.

## git branch feature/code-html
Permet de creer une nouvelle branche feature/code-html

## git checkout feature/code-html
Permet de change de branche et utiliser feature/code-html.

## git checkout -b feature/code-css
Se deplacer vers une nouvelle branche, si elle n'existe pas creer la.

## git pull
Permet de recuperer les changements recent.
Recuperer les changement du repertoire en ligne au repertoire locale.

## git rebase
Permet de recuperer les modifications dans la branche mere.
Les modifications de la branche mere sont placer en dessous des modifications de la branche courantes.
recuperer les modifications de la branche parentes et placer mes modifications au dessus de celle ci.

## git merge
Permet de fusionner les modifications de la feature branche dans la branche principale main.
