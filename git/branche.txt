Creer une branche
 Une branche est un repertoire.
 Sans avoir plusieurs branches, les developpeurs vont se marcher decu.
 La pratique est de creer une nouvelle branche pour chaque fonctionnalite.
 La branche principale pourra vivre independament de la branche creer.

 git branch
 git branch feature/code-html
 git checkout feature/code-html


fatal: The current branch feature/code-html has no upstream branch.

enregistrer les modifications dans feature/code-html a l'aide de git add, commit et push.

retourner a la branch main

Se deplacer vers une nouvelle branche, si elle n'existe pas creer la.
git checkout -b feature/code-css

git pull
